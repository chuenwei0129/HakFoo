# HakFoo

## 为什么叫这个名字

小时候看动漫和武侠片，最燃的瞬间永远是角色出招前的那一声大喊。

《龙珠》的“龟派气功”，《圣斗士》的“天马流星拳”，黄飞鸿的“佛山无影脚”——招式一定要喊出来，不喊出来威力减半。长大后才慢慢琢磨过味儿来：为什么非要喊？

喊出来，是一种确认。告诉自己也告诉对手：这一招，我想清楚了，我要出手了。

喊出来，是一种仪式。把模糊的冲动变成一个明确的名字，从此它可以被记住、被练习、被传承。

当然，最重要的原因可能只有一个：**帅是一辈子的。**

《成龙历险记》里的黑虎阿福把这种精神贯彻到了极致。每一次出招都配一个气势磅礴的名字，“乌鸦坐飞机”，“龙卷风摧毁停车场”，不管对手听不听得懂，自己先喊爽了再说。这种“先报名、再动手”的做派，莫名地击中了我。

于是这个仓库就叫 **HakFoo**。

## 什么是技能

对我来说，**技能就是一个有名字的、可以反复使用的做事方法。**

武术里，招式被命名之后，就从一次偶然的成功，变成了一套可以传承的动作。写代码、做事情也一样。AI 能帮你更快地干活，但它没法替你想清楚“这一步到底在干什么”。给一个动作起名字，就是逼自己先想明白，再动手。

这个仓库存放的是我自己整理和维护的 **Claude Code 技能**。每一个技能都是一个 Markdown 文件，描述了一种具体的做事方式——可能是一个 commit 规范，一个 PR 描述模板，一个调试检查清单，或者一个重构步骤。它们不是一次性指令，而是被我反复验证过、觉得值得留下来的“招式”。

## 基本思路

- **有招必有名。** 想不清楚叫什么，说明还没练到家。
- **招式是用来传承的。** 写清楚“为什么”比“怎么做”更重要。
- **帅是一辈子的。** 命名认真一点，写文档帅一点，自己回头翻的时候也开心。
