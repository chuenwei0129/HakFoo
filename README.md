# HakFoo

小时候看动漫和武侠片，最燃的瞬间永远是角色出招前的那一声大喊。《龙珠》的"龟派气功"，《圣斗士》的"天马流星拳"，黄飞鸿的"佛山无影脚"——招式先有名字，动作才会被记住、被练习、被传承。

《成龙历险记》里的黑虎阿福把这件事推到极致。"乌鸦坐飞机""龙卷风摧毁停车场"这种先报名、再动手的劲儿，一直很打动我。所以这个仓库叫 **HakFoo**。

## 架构

```text
输入层（吸收）→ 理解层（解构）→ 抽象层（模型）→ 输出层（重构）→ 实践层（代码）→ 沉淀层（知识库）→ 演化层（长期迭代）
```

## 设计原则

- 有招必有名
- 技能不是一次性提示词，是可反复使用的认知动作
- 值钱的不是记住多少 API，而是能不能压缩、重写、验证、迁移
